# DotNetCloud.Core.Data.SqlServer

> **Purpose:** SQL Server EF Core migration assembly for DotNetCloud Core data
> **Type:** Migration Assembly
> **Target Framework:** net10.0

## Overview

`DotNetCloud.Core.Data.SqlServer` holds the SQL Server-specific EF Core migrations for the core `CoreDbContext`. It is a thin project that references `DotNetCloud.Core.Data` and contains only the design-time factory and migration files — no business logic or entity models. This separation allows the core data library to remain provider-agnostic while supporting SQL Server as a production database target.

## Key Features

- **SQL Server Migrations** — EF Core migrations targeting Microsoft SQL Server
- **Design-Time Factory** — `CoreDbContextSqlServerDesignTimeFactory` for `dotnet ef migrations` tooling
- **Runtime Assembly Resolution** — Loaded by `Core.Server` at startup for `GetPendingMigrationsAsync()`

## Projects This Interacts With

### Direct Dependencies (Project References)
- `DotNetCloud.Core.Data` — The provider-agnostic core data library (entities, DbContext, configurations)

### Dependent Projects
- `DotNetCloud.Core.Server` — References this assembly for runtime migration discovery and application

## Key Files

| File | Purpose |
|------|---------|
| `CoreDbContextSqlServerDesignTimeFactory.cs` | EF Core design-time factory for SQL Server migration tooling |
| `Migrations/` | SQL Server migration files generated by `dotnet ef migrations add` |
