Overview

The Example module is a reference and demo module for module developers. It demonstrates how to build a complete sandboxed module: its own process, its own database schema, its own web UI, capability calls through the SDK, and domain events.

Creating notes

  1. Select New note.
  2. Fill in the title and content.
  3. Select Save. The note appears at the top of the grid.

Note cards

Notes appear as cards showing their title, content and creation date. Cards are read-only — there is no inline editing. To change a note, delete it and create a new one.

Deleting notes

Each card has a Delete button. Deletion is immediate; there is no undo.

How this UI is hosted

  • The module serves this page from its own process; the core frames it at /apps/dotnetcloud.example/.
  • The frame has an opaque origin: no cookies, no localStorage, no window.top.
  • The core strips the user's session cookie and sends a short-lived dnc-user-assertion. This module's API trusts only that.
  • Theme, locale and shell notifications travel over the dncModuleBridge message protocol.

FAQ

Can I use this module in production?
No. The Example module is a development reference and is not supported for production use.
How do I create my own module?
Use this module as a template: copy the structure, replace the namespaces, then implement your own domain.
