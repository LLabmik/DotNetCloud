Photos

The Photos module keeps a library of the images in your cloud files. It stores its own catalogue — favourites, albums, tags and edit history — and never copies your originals.

Library

  • All photos lists your library newest first, paged in the browser.
  • Favorites and Timeline are different views of it.
  • Shared with me lists photos and albums other people shared with you. Thumbnails come from the owner's cache; the original file stays in the owner's library.

Albums

Create an album in the sidebar, open it, then add photos from the viewer's Add to album menu.

Editing

Edits are non-destructive: the module records rotate, flip and colour adjustments as a stack beside the photo. Save edits regenerates the cached previews with the stack applied; the original file is untouched.

Permissions

The module reads your image files through DotNetCloud with your consent (files:read). Without that consent it can still list the library metadata and cached previews, but it cannot read an image to build a missing preview.
