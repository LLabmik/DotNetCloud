    Bookmarks help

    Overview

    DotNetCloud Bookmarks saves, organizes and searches web links. Browse everything from All bookmarks, star favorites, group links into folders, and switch between grid and list with the toolbar toggle.

    Adding bookmarks

    1. Select New in the sidebar.
    2. Enter the URL and, optionally, a title, folder, description, notes and comma-separated tags.
    3. Select Save.

    Open a bookmark to see its details. Fetch preview asks the server for the page's resolved title, description, favicon, site name and preview image.

    Organizing

    Folders group bookmarks by category; create one with the Folder button and rename or recolor it from the pencil next to its name. Tags categorize across folders, and favorites keep important links one click away.

    Searching

    Type in the search box and press Enter. Results replace the current list until you clear the search.

    Import and export

    Import a browser's bookmarks.html export (Tools → Import) and export everything back to the same format (Tools → Export, which opens in a new tab so your browser can save the file).

    How this UI is hosted

    • The module serves this page from its own process; the core frames it at /apps/dotnetcloud.bookmarks/.
    • The frame has an opaque origin: no cookies, no localStorage, no window.top.
    • The core strips your session cookie and sends a short-lived dnc-user-assertion; this module's API trusts only that.
    • Theme, locale and shell notifications travel over the dncModuleBridge message protocol.
