# SOC 2 Control Matrix (Trust Services Criteria → Controls → Evidence)

**Owner:** engineering
**Last updated:** 2026-08-18
**Companion docs:** `docs/security/SOC2_TYPE_II_AUDITOR_REPORT.md` (draft report), `docs/security/SOC2_AUDITOR_GUIDE.md` (how to test), `docs/admin/SOC2_COMPLIANCE_ADMIN_GUIDE.md` (operator runbooks), `docs/security/PII_INVENTORY.md`.

This matrix maps every applicable Trust Services Criterion to the designed control, where it is implemented, how to test it, and the evidence artifact that demonstrates it. Governance-only criteria (CC1–CC3, parts of CC9) are satisfied by in-repo policy/runbook documents and by operator processes; the code implements the technical controls.

---

## How to use this matrix

1. The **auditor** follows `docs/security/SOC2_AUDITOR_GUIDE.md` and reproduces each control's evidence.
2. The **operator** uses `docs/admin/SOC2_COMPLIANCE_ADMIN_GUIDE.md` to run the audit-package checklist.
3. The **implementation agent** extends this matrix whenever a control changes.
