# DotNetCloud User Documentation

> **Last Updated:** 2026-08-27

---

Welcome to the DotNetCloud user documentation. DotNetCloud is a self-hosted, open-source cloud platform that gives you full control of your data — files, chat, calendar, contacts, notes, media, email, and more, all running on your own server.

These guides cover everything you can do as an end user, from getting started with files to streaming your media library. If you're looking for installation or configuration help, see the [administrator documentation](../admin/) instead.
