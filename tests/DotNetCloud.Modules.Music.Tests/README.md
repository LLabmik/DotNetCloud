# DotNetCloud.Modules.Music.Tests

> **Purpose:** Unit tests for the Music module — music library, playlists, and audio playback
> **Type:** Test Project
> **Target Framework:** net10.0

## Overview

Tests covering the Music module: media scanning, track/album/artist management, playlist CRUD, MusicBrainz enrichment, deduplication, and Blazor UI components.

## Projects Under Test

- `DotNetCloud.Modules.Music` — Music module core library
- `DotNetCloud.Modules.Music.Data` — Music module data layer

## Test Framework

MSTest with Moq for mocking.
